# Contributing to SATOS

## Welcome

Thank you for contributing to SATOS.

## Standards

All contributions must follow the PR standards defined in [docs/PR_STANDARD.md](docs/PR_STANDARD.md).

## Workflow

1. Create a branch for your work
2. Make changes following the PR standards
3. Create a PR with proper evidence
4. Wait for review and approval
5. Merge

## PR Requirements

Every PR must include:
- Structured title (type: description)
- Type label (feat, fix, docs, test, refactor)
- Evidence (video/image for UI, tests for backend)
- Tags/labels

## Getting Help

> SATOS is bootstrapping. Guidelines will evolve.
