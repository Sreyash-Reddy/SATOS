# SATOS Project

This is SATOS — Self-Agent Team Operating System.

## Project Type

Personal AI agent orchestration tool. Manages multiple AI agent teams that collaborate autonomously.

## Key Files

- `.satos/` — SATOS state directory (per-project)
- `docs/PR_STANDARD.md` — PR standards
- `evidence/` — Video/image evidence for changes
- `.github/PULL_REQUEST_TEMPLATE/` — PR template

## Workflow

1. PRD Team defines what to build
2. TRD Team defines how to build it and tests
3. Teams work in loop: build → test → fix → retest
4. Every PR follows structured standards with evidence

## PR Standards

All PRs must follow the standard defined in `docs/PR_STANDARD.md`:
- Structured title
- Type label (feat, fix, docs, test, refactor)
- Evidence (video/image for UI, test results for backend)
- Tags/labels
